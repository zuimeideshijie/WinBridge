## 1. 简介

### 1.1 WinBridge 是什么？

**WinBridge** 是一款为 Linux 桌面系统设计的开源应用程序，它由atomcode为wine开发的ui，它允许用户在 Linux 环境下方便地创建、管理和运行 Windows 应用程序。它通过 **Wine** 技术在 Linux 上模拟 Windows 运行环境，让您能够像在 Windows 电脑上一样运行 Windows 应用。

### 1.2 为什么需要 WinBridge？

对于许多 Linux 用户来说，Windows 应用（如 Microsoft Office、Adobe Photoshop、各类 Windows 游戏等）是日常工作和娱乐不可或缺的一部分。然而，直接在 Linux 上运行这些应用可能会遇到以下问题：

- **兼容性问题**：不同应用需要不同的 Wine 配置。
- **复杂的配置过程**：需要手动设置 Wine 前缀、DLL 覆盖等。
- **多环境管理困难**：同时管理多个不同配置的 Wine 环境非常繁琐。
- **国内下载组件困难**：服务器在国外，下载速度慢或无法连接到服务器

WinBridge 旨在解决这些问题，提供一个**用户友好的图形界面**，让您能够轻松地管理 Windows 应用容器。

### 1.3 核心功能

| 功能 | 描述 |
|------|------|
| **容器管理** | 创建、重命名、删除 Windows 应用容器，每个容器独立运行 |
| **组件管理** | 安装/卸载容器内的 Windows 组件（如 DirectX、.NET Framework） |
| **Wine 版本管理** | 支持系统默认 Wine 或自定义 Wine 版本，一键切换 |
| **任务管理** | 监控和管理正在运行的 Windows 应用进程 |
| **配置管理** | 图形化配置 DLL 覆盖、注册表、容器参数 |
| **主题切换** | 支持亮色/暗色主题切换 |

### 1.4 系统要求

- **操作系统**：Linux（支持主流发行版：Ubuntu、Debian、Fedora、Arch Linux 等）
- **Wine**：建议安装 Wine 7.0 或更高版本
- **磁盘空间**：至少 2 GB 可用空间（每个容器额外需要 1 GB - 10 GB）
- **内存**：建议 4 GB 或以上

## 2. 快速入门

### 2.1 安装与启动
**下载**

见“发行版”


**安装**
```bash
sudo apt install wine
flatpak install WinBridge-x86_64.flatpak
```

**运行 Wine**


```bash
flatpak run WinBridge-x86_64.flatpak
```

首次启动时，您将看到欢迎界面，引导您创建第一个容器。

### 2.2 创建第一个容器

1. 启动 WinBridge，点击欢迎页面的 **"创建第一个容器"** 按钮。
2. 在弹出的对话框中，输入容器名称（例如 `myapp`）。
3. 选择容器架构：**Win32**（32位）或 **Win64**（64位）。
4. 选择 Windows 版本（例如 Windows 10）。
5. 选择 Wine 版本：
   - **系统默认**：使用系统已安装的 Wine 版本。
   - **自定义路径**：指定您下载的独立 Wine 版本路径。
6. 点击 **"创建"** 按钮确认创建。

> 💡 **提示**：创建过程中，WinBridge 会自动初始化 Wine 前缀并进行基本配置，通常需要几秒钟到几分钟。

### 2.3 安装 Windows 应用

容器创建完成后，您可以安装 Windows 应用：

1. 在 WinBridge 主界面左侧侧边栏中，点击您的容器名称。
2. 在容器详情页中，切换到 **"程序"** 标签页。
3. 点击 **"安装程序"** 按钮，选择您的 Windows 安装程序（.exe 或 .msi 文件）。
4. 安装程序将在 Wine 环境中运行，按照正常的安装向导操作即可。

### 2.4 运行 Windows 应用

安装完成后，您可以通过以下方式运行应用：

1. 在 **"程序"** 标签页中，找到已安装的应用。
2. 双击应用图标，或在右键菜单中选择 **"运行"**。
3. 应用将在一个独立的 Wine 容器中启动。

### 2.5 基本界面布局

![主界面布局](../resources/logo.png)

| 区域 | 功能 |
|------|------|
| **标题栏** | 显示当前窗口标题和最小化、最大化、关闭按钮 |
| **菜单栏** | 文件、工具、视图、帮助等菜单 |
| **左侧边栏** | 显示所有容器列表，提供新建/导入容器按钮 |
| **右侧主区域** | 显示容器详情或欢迎页面 |
| **状态栏** | 显示当前 Wine 版本信息 |

## 3. 容器管理

### 3.1 创建容器

**步骤：**

1. 点击侧边栏底部的 **"新建容器"** 按钮，或选择菜单 **"文件 → 新建容器"**。
2. 配置容器参数：

| 参数 | 说明 |
|------|------|
| **容器名称** | 唯一标识，建议使用英文字母和数字 |
| **架构** | Win32（32位）或 Win64（64位） |
| **Windows 版本** | 默认 Windows 10，可根据应用兼容性调整 |
| **Wine 版本** | 系统默认或自定义路径 |

3. 点击 **"创建"** 完成。

### 3.2 重命名容器

1. 在侧边栏中右键点击容器名称，选择 **"重命名"**。
2. 输入新的容器名称，按回车确认。

> ⚠️ **注意**：重命名不会影响容器内的数据和应用。

### 3.3 删除容器

1. 在侧边栏中右键点击容器名称，选择 **"删除"**。
2. 确认删除操作。
3. 容器及其所有数据将被永久删除，请提前备份重要数据。

### 3.4 容器详情

点击容器名称后，右侧主区域显示容器详情，包含以下标签页：

#### 3.4.1 概览

显示容器基本信息：
- 容器名称与架构
- Windows 版本
- Wine 版本
- 磁盘使用情况
- 运行状态

#### 3.4.2 程序

管理容器中安装的 Windows 应用程序：
- **安装程序**：选择并运行安装程序文件
- **运行程序**：启动已安装的应用
- **卸载程序**：从容器中移除应用

#### 3.4.3 组件

管理容器中的 Windows 组件：

| 组件 | 说明 |
|------|------|
| DirectX | 提供游戏和多媒体应用所需的 DirectX 支持 |
| .NET Framework | 运行 .NET 应用所需的框架 |
| Visual C++ Redistributable | 常见 C++ 应用运行库 |
| Gecko | 内置浏览器引擎，用于 HTML 渲染 |
| Mono | .NET 兼容框架，用于运行 .NET 应用 |

**安装组件**：点击 **"安装"** 按钮，选择要安装的组件。
**卸载组件**：点击已安装组件旁的 **"卸载"** 按钮。

#### 3.4.4 配置

高级配置选项：
- **DLL 覆盖**：配置特定 DLL 文件的加载行为（原生/内置/禁用）
- **环境变量**：设置容器内使用的环境变量
- **系统参数**：调整 Windows 版本、屏幕分辨率等

#### 3.4.5 注册表

图形化注册表编辑器：
- 浏览和编辑注册表键值
- 搜索注册表项
- 导入/导出注册表文件（.reg）

## 4. 高级功能

### 4.1 Wine 版本管理

WinBridge 支持使用多个 Wine 版本，您可以为不同容器指定不同的 Wine 版本。

**检查 Wine 版本**

启动时，WinBridge 会自动检查当前使用的 Wine 版本，并在状态栏和"关于"对话框中显示。

**更新 Wine**

1. 点击菜单 **"帮助 → 关于"**。
2. 在"关于"对话框中，点击 **"检查 Wine 更新"** 按钮。
3. 如果有可用更新，程序将从 GitCode 仓库克隆最新版本。

**使用自定义 Wine 版本**

1. 创建容器时，选择 **"自定义路径"** 作为 Wine 版本。
2. 指定您下载或编译的 Wine 版本路径。
3. 该容器将使用指定的 Wine 版本运行。

### 4.2 任务管理器

WinBridge 内置任务管理器，用于监控和管理正在运行的 Windows 应用进程。

**打开任务管理器**

- 点击菜单 **"工具 → 任务管理器"**。

**任务管理器功能**

| 功能 | 说明 |
|------|------|
| **进程列表** | 显示所有正在运行的 Wine 进程 |
| **CPU 使用率** | 显示每个进程的 CPU 占用 |
| **内存使用** | 显示每个进程的内存占用 |
| **结束任务** | 强制终止选中的进程 |

### 4.3 容器导入与导出

**导入容器**

1. 点击侧边栏底部的 **"导入容器"** 按钮。
2. 选择已存在的 Wine 前缀目录。
3. 输入容器名称，点击确认。

**导出容器**

> 目前 WinBridge 支持直接复制容器目录以备份，路径为：
> `~/.local/share/winbridge/bottles/<容器名称>/`

### 4.4 主题切换

WinBridge 支持亮色和暗色两种主题：

- 点击菜单 **"视图 → 切换亮色/暗色模式"**。
- 主题切换会实时更新所有界面元素。

### 4.5 菜单栏功能一览

| 菜单 | 功能 | 快捷键 |
|------|------|--------|
| **文件** | 新建容器、导入容器、退出 | Ctrl+N, Ctrl+Q |
| **工具** | 任务管理器 | Ctrl+T |
| **视图** | 切换亮色/暗色模式 | Ctrl+D |
| **帮助** | 关于 WinBridge、用户手册 | Ctrl+H |

## 5. 故障排除

### 5.1 无法创建容器

**问题**：创建容器时提示失败或错误。

**可能原因与解决方案：**

| 原因 | 解决方案 |
|------|----------|
| Wine 未安装 | 运行 `wine --version` 检查，确认 Wine 已安装 |
| 磁盘空间不足 | 清理磁盘空间，确保有足够空间 |
| 权限不足 | 确保对容器目录有读写权限 |
| Wine 版本不兼容 | 尝试更新 Wine 或使用其他版本 |

### 5.2 应用运行失败

**问题**：安装的应用无法启动或运行异常。

**可能原因与解决方案：**

| 原因 | 解决方案 |
|------|----------|
| DLL 缺失 | 在"配置"标签页中添加相应 DLL 覆盖 |
| 组件缺失 | 安装所需的 Windows 组件（如 DirectX、VC++ Redist） |
| Windows 版本不匹配 | 在"配置"中调整 Windows 版本 |
| 架构不匹配 | 确保容器架构（32/64位）与应用匹配 |

### 5.3 应用显示异常

**问题**：应用界面显示不正常，如文字乱码、界面错位。

**解决方案：**

1. 安装中文字体支持：
   - 复制 Windows 字体文件到容器中
   - 安装 `fonts-wine` 包
2. 调整屏幕分辨率设置：
   - 在"配置"标签页中调整 DPI 设置
3. 启用/禁用虚拟桌面模式

### 5.4 容器管理器无响应

**问题**：WinBridge 界面卡死或无法操作。

**解决方案：**

1. 等待几秒钟，程序可能正在处理任务。
2. 如果长时间无响应，尝试强制退出：
   ```bash
   pkill -f main.py
   ```
3. 重新启动 WinBridge。
4. 如果问题持续，请检查日志文件：
   ```bash
   cat ~/.winbridge/winbridge.log
   ```

### 5.5 常见问题 (FAQ)

**Q: WinBridge 和 Wine 有什么区别？**

A: Wine 是 WinBridge 的底层技术，负责在 Linux 上模拟 Windows API。WinBridge 是 Wine 的一个图形化管理前端，提供更友好的用户界面。

**Q: 一个容器可以安装多个应用吗？**

A: 是的，一个容器可以安装多个应用，它们共享同一个 Wine 前缀。

**Q: 容器之间会互相影响吗？**

A: 不会，每个容器都是独立的 Wine 前缀，拥有独立的配置和环境。

**Q: 如何备份容器？**

A: 复制容器目录即可：`cp -r ~/.local/share/winbridge/bottles/<容器名称> <备份路径>`

**Q: 运行游戏性能如何？**

A: 性能取决于游戏本身和 Wine 对它的支持程度。建议使用 Proton 或游戏专用 Wine 版本以获得更好的性能。

### 6.1 术语表

| 术语 | 说明 |
|------|------|
| **容器** | 一个独立的 Wine 前缀，包含独立的 Windows 环境和配置 |
| **Wine** | 一个允许在 Linux 上运行 Windows 应用的兼容层 |
| **Wine 前缀** | Wine 用于模拟 Windows 环境的目录，包含独立的注册表、系统文件和配置 |
| **DLL 覆盖** | 指定 Wine 应使用原生 Windows DLL 还是内置 Wine DLL 的设置 |
| **Proton** | Valve 开发的基于 Wine 的兼容层，专门用于游戏 |
